# SFTP Travel Impact Model Instructions
Instructions/workflow for uploading a batch of Impact Inventory parquet blobs to the TIM team's SFTP server,
supporting the Scope 3 Cat 6 dataset.

After each flights-pipeline inventory run (e.g. a monthly update), this should be run to push the results to the Google TIM team.

## Generate CSVs
The Google TIM team requires CSV file outputs.

Generate those in e.g. a GCS path like `contrails-301217-bq-sandbox-transfer-tmp-src/google-tim/<YYYY_MM_run_MonthYYYY>` where the `<YYYY_MM_run_MonthYYYY>` is the dataset name with a BigQuery export command like:

```sql
EXPORT DATA OPTIONS (
  uri = 'gs://contrails-301217-bq-sandbox-transfer-tmp-src/google-tim/2019-2026Q2/*.csv',
  format = 'CSV',
  overwrite = true,
  header = true
)  AS
SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2019_run_jun2026_summary`
UNION ALL SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2020_run_jun2026_summary`
UNION ALL SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2021_run_jun2026_summary`
UNION ALL SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2022_run_jun2026_summary`
UNION ALL SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2023_run_jun2026_summary`
UNION ALL SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2024_2025_run_march2026_summary`
UNION ALL SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2026Q1_run_sept2026_summary`
UNION ALL SELECT * FROM `contrails-301217.flights_pipeline_prod.inventory_2026Q2_run_sept2026_summary`;
```

## Origin Blobs
The CSVs generated by the above export were copied to `nick-vm`.

First ssh to `nick-vm` GCP Compute VM.

Become `nickmasson` user with: with the following gloud command from a terminal on the VM:

```shell
sudo -u nickmasson bash
```

Copy files from BQ export GCS bucket:

```shell
gcloud storage cp --recursive gs://contrails-301217-bq-sandbox-transfer-tmp-src/google-tim/2019-2026Q2 .
```


## SFTP data
FTP Server Connection Details:

Username: `feeds-aipk12`
Host: partnerupload.google.com
Port: 19321
SSH key: `/home/nickmasson/.ssh/id_rsa`

To check what files are present on FTP server, connect to ftp server:
```shell
sftp -i /home/nickmasson/.ssh/id_rsa -P 19321 feeds-aipk12@partnerupload.google.com
sftp> ls
```

If there's no existing file structure, create directories to prepare the directory structure like `contrails-impact-inventory/<version>/<upload-date>/<startdate_enddate>`.

```shell
sftp> mkdir contrails-impact-inventory
sftp> mkdir contrails-impact-inventory/v1
sftp> mkdir contrails-impact-inventory/v1/2026-10-07
```

Copy files:

